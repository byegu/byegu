# No24 · 도서 쇼핑몰

[← Profile](../README.md) · [Shop Server](https://github.com/nhnacademy-be5-no24/no24-shop) · [검색 구현 저장소](https://github.com/nhnacademy-be5-no24/no24-frontend)

**2024.03 — 2024.05 · 6인 팀 · 검색·카테고리 등 백엔드 기능 담당**

NHN Academy 교육 과정에서 진행한 온라인 도서 쇼핑몰입니다. 검색, 카테고리, 리뷰, 배송 상태 변경을 담당했고, 일부 도메인과 인증·인프라는 공동 담당으로 참여했습니다.

## 1. 여러 도서 속성으로 검색

Elasticsearch 검색 문서에 도서명·설명·저자·ISBN·출판사를 포함하고, 자소·n-gram 하위 필드와 페이지네이션을 사용하는 검색 흐름을 구현했습니다. 해당 코드는 이름이 `no24-frontend`인 저장소에 있습니다.

검색 기능의 범위는 설명할 수 있지만, 응답 속도·정확도·구매 전환율 개선 수치는 측정 근거가 없어 제시하지 않습니다.

## 2. 계층형 카테고리와 응답 구조

카테고리의 부모·자식 관계를 자기참조 구조로 다루고, 조회 목적에 맞게 응답 DTO를 분리했습니다. CRUD, 중복·미존재 예외, QueryDSL 조회와 Controller/Service/Repository 테스트에 기여했습니다.

주요 고민은 카테고리 깊이와 DTO 반환 형태였습니다. 다만 최종 코드에 최대 깊이·순환 방지 검증이 모두 구현되었다고 주장하지 않습니다.

## 3. 다른 기여와 공동 작업의 경계

- 관리자 기능 진입 시 사용자 역할을 확인하는 Spring AOP Aspect를 구현했습니다. 적용 범위는 `frontend.admin`이며, 누락 토큰 처리 등 보완할 부분이 남아 있습니다.
- 배송 상태 전환 Scheduler의 초기 구현을 추가했습니다. 최종 날짜 조건과 cron은 팀원이 후속 수정했으므로, 최종 로직 전체를 제 단독 성과로 설명하지 않습니다.
- RabbitMQ·Kafka 기술 비교 발표에 참여했습니다. RabbitMQ 서비스 구현과 발표자료의 성능 수치는 제 개인 구현 성과가 아닙니다.

## 결과와 회고

팀으로 SW아카데미 NHN Academy 프로젝트 최종발표회 대상을 수상했습니다. 기능별 담당표와 커밋으로 확인할 수 있는 개인 기여를 중심으로 정리했으며, 팀 전체 테스트 커버리지나 측정값을 개인 지표로 옮기지 않았습니다.

검색과 계층형 데이터 구현을 통해, 저장 모델뿐 아니라 API를 사용하는 쪽에서 어떤 응답 형태가 필요한지도 함께 고려하는 경험을 쌓았습니다.
