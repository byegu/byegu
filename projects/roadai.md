# ROADAI · 도로시설물 훼손 탐지

[← Profile](../README.md)

**2024 · 3인 팀 · AI 데이터 전처리·모델 학습·평가 담당**<br>
개인 AI 작업 기록은 2024.05 — 2024.07에 남아 있습니다.

주행 이미지에서 횡단보도와 과속방지턱을 찾고 훼손 여부를 구분하는 모델을 학습했습니다. 완성 범위는 데이터 전처리와 4개 클래스 탐지 모델의 학습·평가입니다. 실시간 관제 서비스나 유지보수 자동화 시스템을 완성한 프로젝트는 아닙니다.

## 문제: 이미지와 Bounding Box의 불일치

원본 annotation의 Bounding Box가 실제 이미지와 맞지 않는 사례가 있었습니다. 이를 그대로 학습시키지 않고, Segmentation 좌표를 활용해 YOLO 라벨을 구성했습니다.

## 제가 수행한 과정

1. AI Hub 도로 주행 이미지에서 횡단보도·과속방지턱 관련 데이터를 선별했습니다.
2. Segmentation 좌표를 이미지 범위 안으로 제한하고 너비·높이로 나누어 0~1 범위로 정규화했습니다.
3. 온전·훼손 횡단보도와 온전·훼손 과속방지턱의 4개 클래스로 구성했습니다.
4. 데이터를 학습·검증용으로 9:1 분할했습니다.
5. YOLOv8s 학습과 결과 평가를 진행했습니다.

AI 보조를 활용해 코드를 구현하고 직접 검토·실행·검증했습니다. 프로젝트 전체와 비AI 산출물을 제 단독 성과로 설명하지 않습니다.

## 보관된 학습 실행 결과

YOLOv8s · 100 epoch · batch 16 · image size 640 조건의 최종 보관 실행입니다.

| 지표 | 결과 |
| :--- | ---: |
| Precision | 0.77989 |
| Recall | 0.75330 |
| mAP50 | 0.80570 |
| mAP50-95 | 0.58662 |

위 수치는 해당 데이터셋과 모델 실행에서 얻은 프로젝트 결과입니다. 실제 도로 운영 정확도, 안전 향상률, 인력 절감 효과를 의미하지 않습니다. 원천 데이터 스냅샷과 전체 재현 명령은 이 문서에 포함하지 않았습니다.

## 회고

모델 학습 전에 이미지와 라벨의 대응 관계부터 검사해야 한다는 점을 배웠습니다. 같은 작업을 다시 한다면 이미지·라벨 쌍, 누락된 Segmentation과 빈 라벨을 먼저 검증한 뒤 분할·학습을 진행하겠습니다.
